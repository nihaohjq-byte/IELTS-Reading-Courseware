# IELTS Reading Courseware

雅思 / 六级外刊精读课件集：每日外刊主页 + 生词配对测试 + 可交互阅读课件（Pre/While/Post）与学生练习册。

## 在线打开
开启 GitHub Pages 后，直接访问：
- 主页（每日外刊）：https://nihaohjq-byte.github.io/IELTS-Reading-Courseware/
- 生词测试：https://nihaohjq-byte.github.io/IELTS-Reading-Courseware/Vocabulary_Test.html

本地使用：下载整个仓库后双击 index.html（或 ReadingHome.html）即可，无需联网、无需安装。

## 目录结构
- index.html / ReadingHome.html — 每日外刊主页（文章库入口，点击文章进入对应课件）
- Vocabulary_Test.html — 生词配对/卡片测试（含读音、英文释义、中文）
- Forgetting_Lesson/
  - The_Importance_of_Forgetting_Reading_Lesson.html — 主课件（长难句 NPC 分析、划词生词本、导出 PDF 等）
  - The_Importance_of_Forgetting_Student_Worksheet.html — 配套学生练习册
  - content.json / worksheet.json — 课件与练习册的源数据

## 新增每日文章
在 ReadingHome.html 的 ARTICLES 注册表中加入新条目（标题/来源/日期/课件相对路径），并把新课件文件夹一并上传即可。
